Backend API

This interface uses GET /api/vehicles, GET /api/v/:id/state, POST /api/v/:id/command, POST /api/v/:id/manual and POST /api/v/:id/stop. Manual inputs expire automatically if a client stops sending updates. The legacy single-vehicle endpoints (/api/state, /api/command, /api/manual, /api/stop) map to vehicle 1.
